# Fresh GitHub Profile — Setup

1. Create a **public repository whose name exactly matches your GitHub username**.
2. Put `README.md` in the repository root.
3. Upload the complete `assets/` folder.
4. Commit the files.

The README intentionally uses local image paths such as `assets/profile-banner.gif` and `assets/icons/python.svg`, so the visual assets travel with the repository instead of depending on third-party icon URLs.

The profile content is intentionally clean and does not include project placeholders, visitor counters, or decorative button widgets.
